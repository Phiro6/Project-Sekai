# Rhythm Game Project (Unity)

このプロジェクトは、Unityで制作された4レーン形式のリズムゲームです。JSONファイルから譜面データを読み込み、ノーツのタイミング判定、スコアリング、シーン遷移を行う基本的な機能を備えています。

## 使用技術 / 環境
* **Engine:** Unity
* **Language:** C#
* **UI:** TextMesh Pro
* **Data Format:** JSON (譜面データ)

## 主要機能
* **譜面ローダー:** JSON形式の譜面データから、BPMやオフセットに基づいたノーツ生成とタイミング計算。
* **判定システム:** プレイヤーのキー入力（D, F, J, K）とノーツのタイミングを比較し、Perfect/Great/Bad/Missの判定をリアルタイムで実行。
* **コンボ・スコア管理:** 判定に応じたスコア加算とコンボの維持・リセット。
* **演出:** ノーツヒット時のエフェクト生成と、ボタン押下時のレーン発光演出。
* **シーン遷移:** ゲームプレイ終了後に自動的にリザルト画面へ移行。

## コード構成

| スクリプト名 | 役割 |
| :--- | :--- |
| `GManager.cs` | ゲーム全体の状態（スコア、コンボ、判定数）を管理するシングルトン。 |
| `NotesManager.cs` | JSONからの譜面パースと、ノーツの生成・配置処理。 |
| `Judge.cs` | キー入力の監視、判定処理、UI更新、終了後の遷移管理。 |
| `MusicManager.cs` | 音楽のロードと再生、ゲーム開始フラグの制御。 |
| `Notes.cs` | ノーツの移動処理。 |
| `LightController.cs` | キー入力に合わせたレーンの発光演出。 |
| `Result.cs` | リザルト画面のUI表示とリトライ処理。 |

## 使い方
1. プロジェクトをUnityで開きます。
2. `Resources/` フォルダ配下に、再生したい音楽ファイル（AudioClip）と対応するJSON譜面ファイルを配置してください。
3. `MusicScene` を再生し、`Space` キーを押すとゲームが開始されます。
4. ノーツが判定ラインに重なった瞬間に、対応するキー（D, F, J, K）を押してください。
